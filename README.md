# Season 4 Rengar Mod  
A mod that lets you play Rengar in his **Season 4** form.  

---

## Installation  

1. Install **csLol**.  
2. Add the mod:  
   - Click the **`+`** button.  
   - Choose **"Add Raw"**.  
   - Select the folder:  
     ```
     RengarMod/RengarMod/WAD/rengar.wad.client/
     ```  
3. Uncheck **"Remove Unknown"**.  
4. Close the tab and load the mod.
